Guaranteed Domain Rules

  • Zero Float Math: Currency values are tracked as integer minor units with strict decimal formatting.
  • Unmarked ≠ Absent: Someone not explicitly added to a session has no mark, preventing false absenteeism.
  • Append-Only Financial Ledger: Payments and corrections are immutable records; fixes are explicit reversals.
  • No Presumed Multi-Sport Pricing: Rates for players in two games are explicitly typed by management, never guessed.
